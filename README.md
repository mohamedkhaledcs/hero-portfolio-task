# Hero Portfolio - JavaScript DOM Task
A hero portfolio page built entirely with JavaScript DOM manipulation as part of my ITI training task.

## About The Task
The goal of this task was to build a complete hero portfolio section using JavaScript to dynamically create and style the page elements instead of writing the UI directly in HTML.

## Built With
- HTML
- CSS in JS
- JavaScript
- JavaScript DOM Manipulation

- Dynamic DOM Creation
- Custom Mouse Cursor
